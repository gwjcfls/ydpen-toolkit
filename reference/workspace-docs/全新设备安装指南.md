# 全新设备安装指南：Doge 阅读 / Doge 漫画（已内置 fs 插件）

## 交付物

`miniapps/dist/` 目录：

| 文件 | 说明 |
|---|---|
| `doge-comic-1.3.1-fs.amr` | Doge 漫画 1.3.1（541 KB） |
| `doge-reader-1.1.2-fs.amr` | Doge 阅读 1.1.2（1124 KB） |
| `install.ps1` | 一键安装脚本 |

这两个包相对上游 release **只多了两样东西**，JS 代码一字未改（已用 manifest 里的 md5 逐个校验通过）：

1. `libs/arm64/libjsapi_fs_1000000001.so`
2. `libs/arm64-cherry3566/libjsapi_fs_1000000001.so`

这就是我给你这台笔补的 `fs` jsapi（源码 `miniapps/fs-plugin/fs_plugin.c`，md5 `66abc05450e04ac1a08676ed1aa572d2`）。
没有它，阅读器的「本地文件」和整个漫画首页都是白屏。

## 前置条件

**词典笔必须先拿到 root ADB**（也就是 `adb shell id` 返回 `uid=0`）。
全新设备获取 ADB 权限的完整流程见 [../README.md](../README.md) 和 [../战果与使用说明.md](../战果与使用说明.md)
（本机这台 X6 Pro 的密码是 `ydpen2026`）。

确认一下：

```powershell
cd ydpen-adb
tools\adb.cmd devices                 # 必须有 <序列号> device
tools\adb.cmd shell id                # 必须 uid=0；若提示 login with "adb shell auth"：
tools\adb.cmd shell auth              #   输入密码 → success.
```

## 安装方式 A：手动三步（最稳，推荐）

```powershell
cd ydpen-adb

# 1) 推包
tools\adb.cmd push miniapps\dist\doge-comic-1.3.1-fs.amr  /userdisk/Favorite/miniapps/
tools\adb.cmd push miniapps\dist\doge-reader-1.1.2-fs.amr /userdisk/Favorite/miniapps/

# 2) 安装（如果这个 app 之前装过，必须先卸载，否则插件不会被提取！）
tools\adb.cmd shell "miniapp_cli uninstall 8001145141919812"   # 漫画（没装过会报错，忽略）
tools\adb.cmd shell "miniapp_cli uninstall 8001145141919811"   # 阅读（同上）
tools\adb.cmd shell "miniapp_cli install /userdisk/Favorite/miniapps/doge-comic-1.3.1-fs.amr"
tools\adb.cmd shell "miniapp_cli install /userdisk/Favorite/miniapps/doge-reader-1.1.2-fs.amr"

# 3) 验证插件落盘（关键！输出里要有 libjsapi_fs_xxx_<数字>.so）
tools\adb.cmd shell "find /userdisk/miniapp/data/mini_app/pkg -name 'libjsapi_fs*.so'"
```

正常情况下会看到（文件名后面的数字是框架自己加的设备 hash）：

```
/userdisk/miniapp/data/mini_app/pkg/8001145141919812/a/libs/libjsapi_fs_1000000001_768076229.so
/userdisk/miniapp/data/mini_app/pkg/8001145141919811/a/libs/libjsapi_fs_1000000001_604796485.so
```

然后在笔的桌面上点开 **Doge 漫画 / Doge 阅读** 即可。

## 安装方式 B：一键脚本

```powershell
cd ydpen-adb
powershell -ExecutionPolicy Bypass -File miniapps\dist\install.ps1
# 已装过、想强制重装（会清掉该 app 的数据）：
powershell -ExecutionPolicy Bypass -File miniapps\dist\install.ps1 -Force
# 指定设备：
powershell -ExecutionPolicy Bypass -File miniapps\dist\install.ps1 -Serial 192.168.137.191:5555
```

脚本会：找设备 → 校验 root → 推包 → 未安装则安装（已安装且没加 `-Force` 就跳过，避免清数据）→ 逐个验证
`libjsapi_fs*.so` 是否落盘，最后给出结论。

## 三个必须知道的点

1. **覆盖安装不会提取 `libs/*.so`**（我们实测过：同一 appid 已存在时，`miniapp_cli install` 只更新 JS）。
   所以装这两个包之前一定要先 `uninstall`。全新设备天然满足。
2. **卸载会清掉该 app 的数据**（阅读进度、书架、漫画历史等）。要保留数据就先别卸载，
   改用 `python tools\install_fs_plugin.py` 手工把插件推进活跃槽（见 `MINIAPPS.md`）。
3. **架构是 aarch64**（含 `arm64` 与 `arm64-cherry3566` 两套同名插件，框架按机型自选）。
   适用于 X6 Pro 这类 RK3562/RK3566 的 64 位笔；32 位 ARM 的老机型（如 X3s）需要另编 arm 版插件。

## 常见问题

| 现象 | 原因 / 解决 |
|---|---|
| `adb shell id` 返回 `login with "adb shell auth"` | 没认证。执行 `tools\adb.cmd shell auth`，输入密码（如 `ydpen2026`） |
| 装完 `find` 里没有 `libjsapi_fs*.so` | 你是覆盖安装的。先 `miniapp_cli uninstall <appid>` 再装，或加 `-Force` |
| 打开 app 一片白 | ① 屏幕息屏了（框架会暂停渲染），碰一下屏幕；② 插件没落盘，见上一条 |
| 漫画库半天不出内容 | 它在递归扫描 `/userdisk/Favorite`（52 GB 盘），等一会儿；图片文件夹里图片占比 >80% 才会被识别成一本漫画 |
| 阅读器的「本地文件」看不到我的图 | 阅读器只认文本文件，这是它的设计 |
| `miniapp_cli: not found` | 该固件没有 miniapp 框架，装不了小程序 |
| 重启后 app 又打不开 | 插件文件应还在 `pkg/<appid>/<活跃槽>/libs/`；若被清掉，重跑安装脚本。活跃槽写在 `/userdisk/miniapp/resources/slot_info.sh`（内容是 `_a`/`_b`） |

## 想自己重编这个插件

```powershell
cd ydpen-adb\miniapps\fs-plugin
# 需要 zig：https://ziglang.org/download/0.13.0/zig-windows-x86_64-0.13.0.zip
$env:ZIG_GLOBAL_CACHE_DIR="..\..\tools\build\zig-cache-global"
$env:ZIG_LOCAL_CACHE_DIR="..\..\tools\build\zig-cache"
..\..\tools\build\zig\zig.exe cc -target aarch64-linux-gnu.2.29 -shared -fPIC -O2 `
    -I . fs_plugin.c -o libjsapi_fs_1000000001.so
```

编译完把新的 `.so` 替换进 `dist\*.amr` 的 `libs/arm64*/` 并同步 `manifest.json` 的 `cert.md5`
（打包脚本思路见 `MINIAPPS.md`），或者直接用 `python tools\install_fs_plugin.py` 推到笔上。
